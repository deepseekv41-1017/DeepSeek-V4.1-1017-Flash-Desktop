## Reasonix & Ollama Modes
| Mode | Backend | Context Limit |
| --- | --- | --- |
| Reasonix Coding | DeepSeek API / OpenRouter | 1M token window |
| Local Runner | Ollama (`deepseek-v4.1-flash:1017`) | Configurable via `ollama/modelfile.txt` |
